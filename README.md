# Khang Phát Century

Landing page tĩnh giới thiệu dự án Khang Phát Century tại phường Nếnh, Bắc Ninh.

## Chạy trên máy

Mở `index.html` trực tiếp hoặc chạy một static HTTP server tại thư mục gốc. Trang không cần cài đặt và không phụ thuộc framework.

## Cấu trúc

- `index.html`: toàn bộ nội dung landing page.
- `assets/css/styles.css`: giao diện luxury và responsive.
- `assets/js/main.js`: menu mobile, hiệu ứng xuất hiện, lightbox và form đăng ký.
- `assets/images/`: ảnh dự án và ảnh minh họa đã tối ưu.
- `assets/logos/`: logo/brand chính thức dùng trên trang.
- `assets/documents/`: brochure, Q&A đã sửa, chính sách và hồ sơ dự án.
