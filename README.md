# Khang Phat Century

Landing page gioi thieu du an Khang Phat Century tai phuong Nenh, Bac Ninh.

## Chay tren may

Mo `index.html` truc tiep hoac chay mot static HTTP server tai thu muc goc.

## Cau truc

- `index.html`: noi dung trang
- `styles.css`: giao dien responsive
- `script.js`: menu, lightbox, FAQ va form lien he
- `assets/`: anh WebP da toi uu
